# SM_DroneQuad

Редактируемый исходник `SM_DroneQuad.blend` содержит рабочую сцену `SM_DroneQuad` и две сцены превью. В `EXPORT` лежат только меши дрона. Изображение `drone_quadcopter.png`, общая палитра и новый атлас упакованы в Blender. Коробка из `SM_BoxOpen.blend` используется в сцене примерки.

## Передача в Unity

| Файл | Путь назначения |
| --- | --- |
| [SM_DroneQuad.fbx](../../../../Exports/Unity/SM_DroneQuad.fbx) | `Assets/_Project/Models/SM_DroneQuad.fbx` |
| [T_DroneQuad_Decals.png](T_DroneQuad_Decals.png) | `Assets/_Project/Textures/T_DroneQuad_Decals.png` |

Для слота `DRONEWORKS_Palette` назначь существующий игровой материал с `T_Palette_DRONEWORKS.png`. Для `DRONEWORKS_DroneQuad_Decals` создай материал `Universal Render Pipeline/Lit` с атласом в Base Map и Alpha Clipping около 0,4. Для атласа используй sRGB, Alpha Is Transparency, Clamp и Bilinear. В префабе выключи `QcStamp` и 12 объектов `Crack_*` по умолчанию. Трещина каждой детали находится под её мешем и движется вместе с ним. Поза покоя задана геометрией винтов, вращение задаёт `QCStandView`.

Профиль FBX использует Unit Scale 1.0, Forward −Z, Up Y, FBX Units Scale и включённый Apply Transform. Для импорта используй Scale Factor 1, Convert Units и Preserve Hierarchy, Bake Axis Conversion выключен, Normals = Import.

## Замеры

| Проверка | Результат |
| --- | --- |
| Дрон в покое по X × Y × Z Unity | 0,7296 × 0,3500 × 0,7296 м, 4 954 треугольника, 25 мешей |
| Опора и камера | `Body` в центре рамы, низ на Y = −0,175 м. При Y = 1,125 м четыре опоры касаются площадки `SM_StationQC`. Объектив открыт в +Z. |
| Вращение | Четыре собственных pivot на Y = 0,155 м. Винты 0/2 и 1/3 вращаются в противоположных направлениях. Полный оборот проверен с шагом 5°, зазоры проверены по непрерывным дискам. Диаметр 334,12 мм, минимум 76,0 мм между дисками и 17,3 мм до корпуса по высоте. Между лопастью и её мотором минимум 7,25 мм. |
| Задний щит | Диск заднего винта проходит в проёме `SM_StationQC`, радиальный просвет 429 мм. До лицевой плоскости сплошного щита текущей заглушки `Station_QC` остаётся 2,94 мм. Из-за этой плоскости диаметр винта выбран около 334 мм. |
| Коробка | При масштабе 0,9 габариты 0,65664 × 0,315 × 0,65664 м. Зазор до стенок по 11,68 мм с каждой стороны, до закрытых клапанов 85,4 мм. На Y = 0,1775 м опоры стоят на дне. Это на 22 мм выше текущей точки Y = 0,1555 м. Смещение относится только к представлению дрона в коробке. |

Проверены сохранённый исходник и свежий импорт FBX в Blender 5.2.4 LTS. Экспортная копия под `.local/checks/drone-quad` открывает скрытые декали и компенсирует повторное преобразование вложенных мешей штатным FBX-экспортёром при Apply Transform. В редактируемой сцене декали скрыты, а их локальные трансформации исходные.

Импорт финального FBX в изолированный Unity 6000.3.28f1 подтвердил 25 мешей, габариты, иерархию, точки вращения, вертикальную локальную Y, направление объектива, UV и слоты материалов. Обе текстуры импортированы, у атласа проверена альфа. Замеры Unity в [журнале импорта](../../../../.local/checks/drone-quad/unity-precompiled/drone-import-result.txt). Проверка шейдинга в игровом URP-префабе входит в приёмку `TestFactory`.
