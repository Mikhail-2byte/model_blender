# SM_Truck для DRONEWORKS

19 ноября 2026. Трёхосный грузовик готов к подстановке в визуальную часть префаба. Модель собрана в мастерской по [листу грузовика](../../../../References/truck_sheet.png) и [ART_SPEC](../../../../Docs/ART_SPEC.md).

Геометрия, камуфляж и эмблема созданы для DRONEWORKS скриптом [build_truck.py](build_truck.py). Три оттенка камуфляжа взяты из семейства CAMO, логотип отрисован в скрипте. Камуфляж и эмблема запечены вместе в цветовой атлас для второго слота кузова кабины.

## Контроль посадки

| Параметр | Замер |
| --- | --- |
| Габариты в осях Unity, X × Y × Z | 6,20 × 2,30 × 2,30 м |
| Границы от корня `Body` | От (−3,30; 0,00; −1,15) до (+2,90; 2,30; +1,15) м |
| Настил кузова | 3,60 × 2,00 м в плане, верх на Y = 1,00 м |
| Верх заднего борта и дальнего борта | Y = 2,00 м |
| Верх переборки | Y = 2,30 м |
| Откидной борт | Сторона +Z, верх на Y = 0,994 м. Шарнир в (−1,50; 0,975; 0,995) м. |
| Сетка 4 × 2 × 2 | Свободный объём 3,20 × 0,88 × 1,60 м от (−3,10; 1,00; −0,76) м. Откидной борт проходит над шинами. |
| Колёса | Ø 0,90 м, ширина 0,30 м. Центры по X −2,60 / −1,00 / +1,90 м при Y = 0,45 м и Z = ±1,00 м. На каждой оси первым идёт колесо на +Z. |
| Треугольники | 23 484 в исходнике, после обратного импорта FBX и в Unity. Бюджет 25 000. |

Корень `Body` объединяет кабину и раму. Его прямые потомки — `CargoBed`, `Board_Side` и `Wheel_0…Wheel_5`. Каждое колесо сохраняет pivot на ступице. Локальная +Y колеса в Unity направлена вдоль −Z машины, поэтому положительный угол кода `TruckView` уводит нижнюю точку протектора к −X при движении машины к +X.

Шестнадцать проверочных коробок сохранены в скрытой коллекции `CHECKS - 16 cargo cells`. В экспорт попадали только меши из `EXPORT`. [Сцена блокинга](../../../../.local/checks/truck/SM_Truck_Blockout.blend) · [Превью с заполнением](../../../../.local/checks/truck/Blockout_Fit.png)

## Импорт

FBX создан командой мастерской с Unit Scale 1,0, Forward −Z, Up Y, FBX Units Scale и включённым Apply Transform. В изолированном проекте Unity 6000.3.28f1 использован Scale Factor 1. Convert Units и Preserve Hierarchy включены, Bake Axis Conversion выключен. Проверены габариты, нулевой поворот корня, кабина по +X, открытый борт по +Z, настил и проворот каждого колеса на 90° формулой из `TruckView`. [Замеры Unity](../../../../.local/checks/truck/unity/import-result.txt)

В DroneGame нужны FBX и новый атлас. Для `DRONEWORKS_Palette` назначь общую палитру как Base Map с Point, Clamp, без mipmaps и сжатия. Для `DRONEWORKS_TruckDecals` назначь новый sRGB-атлас как Base Map непрозрачного URP/Lit. FBX содержит оба слота материалов, пакетный прогон Unity проверил импорт обоих PNG, а загрузка URP-пакетов в тестовом проекте остановилась на ошибке Unity Package Manager. Проверку отображения материалов и подстановки в префаб следует провести в DroneGame.
