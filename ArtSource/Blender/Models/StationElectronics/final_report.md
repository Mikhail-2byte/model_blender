# Станция электроники DRONEWORKS

Готовы [редактируемый проект Blender](SM_StationElectronics.blend), [игровой FBX](../../../../Exports/Unity/SM_StationElectronics.fbx) и два превью Cycles в 1450 × 1450 px, [спереди](SM_StationElectronics_Front.png) и [со стороны выдачи](SM_StationElectronics_Output.png). Модель воспроизводится [скриптом bpy](build_electronics.py) из шаблона мастерской. Стойки таблички и держатель лампы входят в `Base`. Размеры `Cabinet` относятся к закрытому шкафу с панелями и крепежом, а размеры `SignBoard` по X и Y — к раме таблички.

## Примерка

Проверка по треугольникам прошла на блокинге и повторно на игровом FBX. Рама 0,73 × 0,19 × 0,73 м помещается на настиле и проходит над передним бортиком. Дрон 0,73 × 0,35 × 0,73 м в точке выдачи (−1,25, 1,10, 0) имеет по 55 мм запаса по X и по 105 мм по Z. После подъёма на 75 мм проверен прямой вынос по −X. С высоты глаз 1,65 м луч достигает настила приёмника с 1,566 м, а выдачи — с 1,511 м. ## Перенос в Unity

В `Assets/_Project/Models/` нужен только [SM_StationElectronics.fbx](../../../../Exports/Unity/SM_StationElectronics.fbx). Для `DRONEWORKS_Palette` назначь существующую `T_Palette_DRONEWORKS.png` как Base Map материала URP/Lit с белым Base Color. Её UV выбирают ячейки общей палитры с Point, Clamp, без mipmaps и сжатия. Для `Light_0…2` и `Lamp` используй свои URP-материалы с Base Color и Emission либо задавай оба свойства по отдельности на каждом рендерере. Подложка штамповки использована как образец формы, источники описаны в [reference_notes.md](reference_notes.md).

Экспорт мастерской выполнен с Unit Scale 1.0, Forward −Z, Up Y, FBX Units Scale и Apply Transform. В Blender 5.2.4 LTS FBX повторно импортирован в чистую сцену, проверены габариты, оси, pivot, иерархия, материалы и UV. Отдельный импорт в Unity 6000.3.28f1 подтвердил эти параметры при Scale Factor 1, Convert Units и Preserve Hierarchy включены, Bake Axis Conversion выключен, Normals = Import. Package Manager завершил загрузку пакетов с ошибкой, поэтому Unity-проверка геометрии выполнена без Package Manager. [Замеры Unity](../../../../.local/checks/station-electronics/unity-core/import-result.txt)

Следующий шаг по D2 — подставить ассет в `Station_Electronics` в DroneGame, назначить материалы URP и в игровом режиме проверить три строки текста, обе полосы, смену цветов и выдачу дрона.
