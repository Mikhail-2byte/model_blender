## Размеры и примерка

| Что проверено | Результат |
| --- | --- |
| Диаметр вращения, включая оранжевые кончики | **334,16 мм** при пределе 400 мм |
| Ширина одной лопасти в плане | **53,11 мм** при пределе 60 мм |
| Габариты в покое по X × Y × Z Unity | **333,73 × 20,00 × 73,41 мм**. В ширину Z входит ступица |
| Pivot и посадка | Центр ступицы на половине толщины, ось вращения — локальная Y Unity. Низ ступицы на −10 мм. При смещении относительно мотора на +70 мм контакт на +60 мм |
| Треугольники | **284** у `Propeller` и **16** у `Crack`. Всего **300** |
| Просвет над мотором | Не менее **5,40 мм** под лопастями по всему обороту. Ступица касается мотора |
| Между соседними винтами | Не менее **75,96 мм** между кругами вращения |
| Над неподвижным корпусом дрона и рамой | Не менее **17,30 мм** и **120,00 мм** соответственно |
| До стенда `SM_StationQC` | Минимальный горизонтальный просвет **356,42 мм** до геометрии в слое вращения. Задний винт проходит через проём |
| До сплошного щита в текущем `Station_QC.prefab` | Не менее **2,92 мм** при штатном положении дрона, по геометрии заглушки |

Четыре копии проверены на высоте Y = 0,155 м. В исходной позе винты 0 и 2 лежат вдоль Z, 1 и 3 — вдоль X. Пары вращались навстречу друг другу от 0° до 360° с шагом 1°. Для зазоров также проверены круги вращения целиком, включая промежуточные углы. Для посадки использована геометрия четырёх моторов из `SM_DroneQuad.fbx`. Плоскость контакта и просвет также проверены по размерам контрольного цилиндра Ø 150 × 120 мм.

В актуальном задании предел составляет 400 мм, в `Docs/ART_SPEC.md` осталась строка 500 мм. Диаметр выбран с запасом до сплошного щита из текущего игрового префаба. Форма взята с переднего правого винта на `drone_quadcopter.png`. Верхние угловые кадры `storyboard_02_hud.jpg` использованы для масштаба сборки и ракурса ОТК. Геометрия создана в Blender Python, палитра и подложка из проекта упакованы в исходник. Подложка и примерочный мотор находятся вне экспорта.

## Перенос в Unity 6.3 URP

Единственный файл для переноса — [SM_Propeller.fbx](../../../../Exports/Unity/SM_Propeller.fbx), назначение `Assets/_Project/Models/SM_Propeller.fbx`. Для обоих мешей назначь имеющийся `Assets/_Project/Materials/DRONEWORKS_Palette.mat`. Лопасти и ступица используют RUBBER, кончики — SIGNAL. Трещина сделана геометрией с UV на той же палитре. Новых текстур нет.

Параметры экспорта Blender — Unit Scale 1.0, Forward −Z, Up Y, FBX Units Scale, Apply Transform включён. Параметры импорта Unity — Scale Factor 1, Convert Units и Preserve Hierarchy включены, Bake Axis Conversion выключен, Normals = Import. В FBX два меша, `Propeller > Crack`. В игровом префабе выключи `Crack` для целой детали и включай при повреждении.

В изолированном Unity 6000.3.28f1 подтверждены размеры, масштаб, иерархия, локальная ось Y, оборот на 360°, UV и слот палитры. [Замеры Unity](../../../../.local/checks/propeller/Unity63Retry/propeller-unity-result.txt)

У игрового материала проверены ссылки на URP/Lit и общую палитру. Проверка в редакторе прошла в режиме без Package Manager. При запуске с URP редактор завершился из-за тайм-аута связи с Package Manager, поэтому шейдинг в игровой сцене остаётся проверить. [Журнал запуска URP](../../../../.local/checks/propeller/unity63-urp.log)

Следующий шаг D2 — подключить винт в `Part_Propeller` и в четыре позиции на собранном дроне. Затем проверить захват детали, установку и запуск ОТК в `TestFactory`.

## Воспроизведение

[Сборка модели и камер](build_propeller.py) · [Проверка исходника и FBX](check_propeller.py) · [Замеры исходника](../../../../.local/checks/propeller/blend.json) · [Замеры FBX](../../../../.local/checks/propeller/fbx.json) · [Технические ракурсы](../../../../.local/checks/propeller/multiview/contact_sheet.png) · [Трещина после импорта FBX](../../../../.local/checks/propeller/fbx_damage.png)

В `SM_Propeller.blend` сцена `SM_Propeller` содержит редактируемые меши. Сцены `Top` и `Motor Fit` воспроизводят оба превью. Рендер выполнен в Blender 5.2.4 LTS, Cycles CPU, 48 сэмплов с денойзингом и Khronos PBR Neutral, 1320 × 700 и 1320 × 980 пикселей. Оба кадра заняли около 79 секунд вместе с загрузкой файла.

При повторном экспорте из сохранённого исходника используй `build_propeller.py -- --prepare-export` в Blender CLI для создания копии с видимым `Crack` в `.local/checks/propeller/SM_Propeller.export.blend`. Экспортируй эту копию через `Tools/Blender/blender.ps1 -Mode export`.
