# DRONEWORKS — модели: размеры и требования

Для художников (Blender, Meshy). Стиль и цвета — [ART_STYLE.md](ART_STYLE.md). Образцы — [References/](../References/).

> Рабочая копия спецификации DroneGame. Для пробного экспорта в мастерской есть уточнение пункта 2 по трансформациям. См. [инструкцию мастерской](BLENDER_WORKFLOW.md).

**Размеры сняты со сцены TestFactory и префабов** (по мешам и сверены с коллайдерами). Сейчас в игре стоят заглушки из примитивов — новые модели должны **сохранить габариты и ключевые точки**, иначе поломаются лотки, гнёзда, ячейки кузова, захват.

Обозначения:
- Габариты **X × Y × Z, метры, Y — вверх**. «Перед» модели — **+Z** (кроме оговорённых).
- **Pivot** — точка опоры (начало координат модели).
- **Приоритет:** 1 — нужно сейчас, 2 — после теста с игроками, 3 — будущее.
- **Тр.** — бюджет треугольников (верхняя граница).

## 2. Правила экспорта (Blender → Unity)

1. **FBX**, единицы — метры: Scene Properties → Units → Unit Scale **1.0**, Length **Meters**. 1 единица = 1 м.
2. Перед экспортом: выделить всё → **Ctrl+A → All Transforms** (масштаб 1, поворот 0).
3. Экспорт FBX: **Forward = −Z Forward**, **Up = Y Up**, «Apply Scalings» = **FBX Units Scale**, галочка **Apply Transform**, без камер и света.
4. Проверка в Unity (Inspector модели → Model): Scale Factor **1**, Convert Units включено. Модель, поставленная в сцену с поворотом 0, **не лежит на боку**, её габариты совпадают с таблицей (смотреть Bounds в Inspector или поставить рядом заглушку).
5. **«Перед» модели смотрит в +Z Unity** (в Blender это −Y). Исключения оговорены в таблицах.
6. **Pivot:** у предметов (то, что берут в руки) — **в центре** габарита; у оборудования — **внизу по центру** основания.
7. **Части, которые двигаются, светятся или ставятся в гнездо — отдельными объектами** с pivot в точке вращения/крепления. Имена частей — **латиницей**, как в таблицах (код ищет их по имени).
8. **Коллайдеры не делаем** — их собираем в Unity из простых форм.
9. Материалы: основной — палитра `T_Palette_DRONEWORKS` (см. ниже), декали — **отдельный материал** (второй слот).
10. Имена файлов: `SM_<Имя>.fbx` для неподвижных/жёстких моделей, `SK_<Имя>.fbx` для моделей со скелетом (персонаж, руки). Кладём в `Assets/_Project/Models/`.
11. Персонаж: **T-поза**, рост ~1,8 м, один меш (или голова отдельно), без скелета — скелет даёт **Mixamo**.
12. Каждый ИИ-ассет (Meshy, Tripo и т. п.) — запись в `Assets/_Project/CREDITS.md` с **тарифом и лицензией на момент генерации** (см. раздел «Meshy»).

## 3. Покраска по палитре

Текстура `Assets/_Project/Textures/T_Palette_DRONEWORKS.png`, 256 × 256: сетка 8 × 8 квадратов по 32 px. В каждом ряду две семьи цветов: слева столбцы 0–2, справа 4–6 (**тёмный · основной · светлый**); столбцы 3 и 7 — запасной повтор основного. Подписи и HEX — [References/palette.png](../References/palette.png). Пересобрать палитру: `uv run --with pillow python Tools/Palette/make_palette.py`.

В Blender:
1. Материал модели: Principled BSDF, Base Color ← Image Texture `T_Palette_DRONEWORKS.png`, **Interpolation: Closest** (иначе цвета смешиваются на границах).
2. Развёртка: выделить грани одного цвета → UV → Unwrap (или Project From View) → в UV Editor **сжать островок (S → 0)** и перенести в центр нужного квадрата. Островок может быть крошечным — важен только цвет под ним.
3. Тёмный/светлый оттенок той же семьи — для скосов и граней «в тени»/«на свету», если хочется мягкой объёмности без запекания.
4. Мелочь (логотип, полосы, знаки, лица) — **не палитрой, а декалью**: отдельный материал (второй слот) с атласом `T_Decals_DRONEWORKS.png` (прозрачный фон).
5. В Unity: импорт палитры — Filter **Point**, без Mip Maps, без сжатия, Wrap **Clamp** (уже настроено).

Палитрой красим **простые модели**: стены, ящики, стеллажи, лотки, столы, щиток, всё, что делаем руками. Модели из Meshy могут оставаться со своей текстурой.

## 4. Meshy

Референсы и модели делаются в **Meshy (meshy.ai)**.

**Шаблон запроса** (держим одинаковым, меняем только `<ОБЪЕКТ>` и `<ДЕТАЛИ>`):

```
Stylized cartoon 3D game asset: <ОБЪЕКТ>. <ДЕТАЛИ>.
Chunky soft shapes, beveled edges, large bolts and rivets, thick sturdy legs, no small details.
Colors: dark blue-grey metal (#585D7F), signal yellow-orange (#F2A608) on moving and interactive parts,
black-and-yellow hazard stripes, dark rubber (#34323D), clean flat colors, soft studio lighting.
Toy-like proportions, game-ready, centered, front view facing camera, plain dark background.
```

Негатив (Negative prompt): `realistic, photoreal, rust, dirt, scratches, tiny details, text, letters, weapons, military insignia, star emblem, flags, logos of real brands, noise`.

Примеры `<ОБЪЕКТ>/<ДЕТАЛИ>`:
- `industrial stamping press machine` / `yellow press head with hazard stripes, green ball lamp on top, empty sign board, input tray in front, output tray on the left side, yellow feet`
- `military-style six-wheel cargo truck` / `olive camouflage, open wooden cargo bed, DRONEWORKS logo on the door instead of a star`
- `cartoon factory worker character, T-pose` / `white round head without face, navy blue overalls with reflective stripes, navy cap with white drone silhouette, black boots`

Настройки и порядок:
1. Стиль — Cartoon / Stylized. **Target polycount** — по колонке «Тр.» из таблиц ниже (для частей — по их сумме).
2. Текстура Meshy допускается (Base Color). PBR-шероховатость/металл — по желанию, лучше без них.
3. **После Meshy — в Blender:**
   - масштаб под габариты из таблицы (поставить рядом куб нужного размера);
   - pivot — по правилу (предмет — центр, оборудование — низ по центру);
   - **разделить подвижные/светящиеся/вставляемые части** на отдельные объекты с именами из таблицы, поставить им pivot в точку вращения;
   - почистить лишнее (подставки, фон), проверить нормали;
   - экспорт по разделу 2.
4. **CREDITS:** у каждой модели — тариф Meshy на момент генерации:
   - **Free** — лицензия **CC BY 4.0**, нужна строка «Model created with Meshy – CC BY 4.0 License» в титрах и на странице Steam;
   - **Pro и выше** — без указания.
