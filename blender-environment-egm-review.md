# EGM · Проверка плана Blender для DRONEWORKS

19 ноября 2026. [Инструкция мастерской](Docs/BLENDER_WORKFLOW.md).

«Слон» изучил правила проекта, спецификацию, палитру и 11 изображений в `Docs/References/`, нашёл сохранённую настройку в проекте «Моделирование 3D по чертежам» и составил план. Три независимых рецензента прочитали первый черновик в отдельных контекстах. Один проверил выбор подхода и границы задачи, второй — возможность воспроизвести приёмку, третий пересказал план без контекста из истории чата.

| Что нашла «Золотая рыбка» | Как «Слон» поправил план |
| --- | --- |
| Применение `All Transforms` может сместить origin дочерней детали. Превью Blender способно выглядеть правильно, даже если Unity импортирует неверную точку вращения. | Задан порядок `Rotation & Scale → origins → экспорт` с сохранением локальной позиции. В Unity проверяются конкретные координаты, поворот детали на 90°, габариты и знаки осей. Изменение ART_SPEC привязано к результату реального прогона. |
| Запуск Blender, импорт в Unity и подключение Codex допускали разные толкования готовности. | Установлены отдельные рубежи для моделирования, сдачи FBX и подключения Codex. В статусе отдельно отмечаются stdio и нативный вызов MCP. |
| Успешный экспорт из тестового скрипта мог разойтись с тем, как экспортирует художник. | У обоих один скрипт и одна конфигурация. Контрольный меш вне `EXPORT` проверяет фильтр. Переоткрытие вложенного файла после Save As проверяется в чистой копии с пробелом и кириллицей в пути. |
| В проверке палитры, доказательствах и исключениях Git не хватало конкретики. | Указаны точные UV и цвета, проверки Unity-материала, имена каталогов, файлы прогона и проверка временных ассетов вместе с их `.meta`. |
| Другой участник не сможет повторить подключение по ссылке на соседнюю папку. | Зафиксированы источник, ревизия и зависимости MCP, проектный каталог локальной среды и отдельная проверка после загрузки конфигурации Codex. |
| Первая модель конвейера потребует проверки, которую временный FBX не покрывает. | Вынесена проверка стыковки, ссылки на `Belt`, материала стрелок и прокрутки UV в обе стороны. У персонажа и анимаций остаётся собственная приёмка. |

Четвёртый рецензент в свежем контексте подтвердил, что замечания отражены в плане и можно начинать инвентаризацию. По контрольному чтению дополнительно уточнены временное исключение из ART_SPEC для пробника, общий режим экспорта для пробника и художника, порядок проверки профилей FBX, точка входа и контрольные суммы MCP.

Фактические запуски Blender, импорт Unity и вызов MCP в DroneGame предстоят на этапе настройки.
